# SETOLIA

OBS Studio 用セットリストプラグイン

## 主な機能

- 配信時間に同期したタイムスタンプ
- リアルタイム時計表示
- [歌詞検索サイト](https://utaten.com)へのショートカットボタン
- 設定済みブラウザソース追加ボタン
- カスタムテンプレートに対応
- Stream Deck・ホットキーからの操作に対応

## 1.3.0 の変更点

更新後も設定やシーンはそのまま使えます。利用者の操作は必要ありません。

- OBS 33 に対応しました(新しいプラグインの構成と、OBS 32 以前の構成の両方に対応)。
- テンプレートをプラグインの HTTP サーバーから配信するようになりました。以前のバージョンで追加したテンプレートのブラウザソースは自動で変換されます。
- HTTP サーバーのポートをドックから変更できるようになりました。使用中のポートを指定した場合は、元のポートのまま動作し続けます。
- カスタムテンプレートを OBS の設定フォルダ(ユーザーテンプレートフォルダ)に置けるようになりました。以前のバージョンで同梱テンプレートのフォルダに置いていたカスタムテンプレートは自動でコピーされ、アンインストールしても消えません。
- Web ページからの曲送り(`/next`)を拒否する設定を追加しました(既定は無効)。
- 「SETOLIA: 次の曲」ホットキーを追加しました。
- 設定を編集のたびに自動で保存するようにしました。OBS が異常終了しても、直前までの編集が残ります。
- 長時間の配信でもタイムスタンプがずれないようにしました。OBS の起動時にすでに配信中の場合も、タイムスタンプが進みます。
- OBS 32 以降のプラグインマネージャーに、名前とバージョンが表示されるようになりました。

## インストール方法

Windows、MacOS、Linux 用のバイナリは、[リリース](https://github.com/Yagami-Huki/setolia/releases)ページで入手可能です。

また、[Booth](https://logicbox.booth.pm/items/7541386) にて最新の Windows 用のインストーラーを入手可能です。

Windows 版は OBS 33 の新しいプラグイン構造と、OBS 32 以前の構造の両方に対応しています。

### Windows(zip で手動インストールする場合)

zip の中身を `C:\ProgramData\obs-studio\plugins\setolia\` に展開してください。展開後は次のような構成になります。

```
C:\ProgramData\obs-studio\plugins\setolia\
├── setolia.dll          (OBS 33 以降が読み込む)
├── bin\64bit\setolia.dll (OBS 32 以前が読み込む)
└── data\
```

2 つの `setolia.dll` は同じファイルです。OBS 33 以降は直下の dll を読み込み、`bin\64bit` にある方はスキップします。

### Windows(ポータブル版の OBS)

- OBS 33 以降:`<OBS>\plugins\setolia\setolia.dll` と `<OBS>\plugins\setolia\data\`(ポータブル版では `C:\ProgramData` のプラグインは読み込まれません)
- OBS 32 以前:`<OBS>\obs-plugins\64bit\setolia.dll` と `<OBS>\data\obs-plugins\setolia\`

### 旧バージョンからの更新時の注意

以前のバージョンを `C:\Program Files\obs-studio\obs-plugins\64bit\setolia.dll` に置いていた場合、OBS 32 以前ではプラグインが重複して読み込まれることがあります。インストーラーは旧ファイルを検出すると削除するかを確認します。zip で手動インストールする場合は、旧ファイル(`obs-plugins\64bit\setolia.dll` と `data\obs-plugins\setolia\`)を削除してください。

## 使用方法

[Booth](https://logicbox.booth.pm/items/7541386) にてユーザーマニュアルを公開しているため、こちらをご参照ください。

### OBS 33 以降をお使いの場合

OBS 33 では、ローカルファイルとして読み込んだブラウザソースから `127.0.0.1` への通信がブロックされるため、テンプレートはプラグイン内の HTTP サーバー(`http://127.0.0.1:8080/templates/...`)から配信するようになりました。

以前のバージョンで追加したテンプレートのブラウザソースは、OBS の起動時およびシーンコレクションの切り替え時に自動で URL 方式に変換されるため、テンプレートを再追加する必要はありません。旧バージョンのインストール先(`C:\Program Files\obs-studio\data\obs-plugins\setolia\templates\...` や、ポータブル版 OBS 32 の `<OBS>\data\obs-plugins\setolia\templates\...`)を参照しているソースも、同じ名前のテンプレートがあれば変換されます。

### ホットキーで曲送りする

OBS の「設定 → ホットキー」に「SETOLIA: 次の曲」があります。キーを割り当てると、ドックの「次の曲」ボタンや `POST /next` と同じ動作をします。割り当ては SETOLIA の設定に保存され、次回起動時にも使われます。

Stream Deck からは、標準の「ホットキー」アクションで、割り当てたキーを送ることでも呼び出せます。HTTP(`/next`)を使わないため、下の「Web ページからの曲送りを拒否する」を有効にしたい場合の代わりの手段としても使えます。

### Web ページからの曲送りを拒否する(任意)

`POST /next`(曲送り)には認証がないため、ブラウザで開いた Web ページからも呼び出せます。ドックの「ブラウザ(Web ページ)からの曲送りを拒否する」を有効にすると、`/next` は次の場合だけ受け付け、それ以外は `403` を返します。既定は無効で、今までどおり動作します。

- `Origin` ヘッダーが付いていない(curl や、多くの Stream Deck プラグイン)
- `Origin` が `http://127.0.0.1:<ポート>` または `http://localhost:<ポート>`

Stream Deck のプラグインによっては、内部のブラウザ部品から `Origin` ヘッダー付きで送るものがあり、その場合は有効にすると曲送りできなくなります(その場合は上のホットキーを使ってください)。`Origin` 付きの `/next` を受けると、設定にかかわらず OBS のログに `POST /next with Origin '...'` と出力されます(同じ Origin は起動ごとに 1 回)。有効にする前に、お使いのプラグインで曲送りしてログを確認してください。

### サーバーのポートを変更する

HTTP サーバーは既定でポート `8080` を使用します。他のアプリが 8080 を使用している場合は、ドックに「ポート 8080 は使用できません」と赤字で表示されます。ドック下部の「サーバーポート」に別の番号(1024〜65535)を入力して「適用」を押すと、サーバーがそのポートで再起動し、既存のテンプレートのブラウザソースの URL も新しいポートに書き換えられます。設定は保存され、次回起動時も使用されます。

Stream Deck などから `http://127.0.0.1:8080/next` を呼び出している場合は、そちらの URL のポート番号も変更してください。

新しいポートが他のアプリに使われている場合は、サーバーは元のポートのまま動き続け、ドックに「ポート <新> は使用できません(<旧> で稼働中)」と表示されます。この場合、設定は変更されません。

### カスタムテンプレート

カスタムテンプレートは、OBS の設定フォルダ内のユーザーテンプレートフォルダに置きます。ドックの「テンプレートフォルダを開く」を押すと、このフォルダが開きます。

| OS | ユーザーテンプレートフォルダ |
| --- | --- |
| Windows | `%APPDATA%\obs-studio\plugin_config\setolia\templates` |
| macOS | `~/Library/Application Support/obs-studio/plugin_config/setolia/templates` |
| Linux | `~/.config/obs-studio/plugin_config/setolia/templates` |

- 同梱テンプレート(インストール先の `data\templates`)のフォルダをこのフォルダにコピーし、名前を変えて編集してください。フォルダが空のときは、使い方を書いた `README.txt` が置かれます。
- テンプレートの一覧には、ユーザーテンプレートと同梱テンプレートの両方が表示されます。同梱テンプレートと同じ名前のフォルダを置くと、ユーザーテンプレートが優先されます(ファイル単位で優先されるため、ユーザー側にないファイルは同梱テンプレートのものが使われます)。
- ユーザーテンプレートフォルダは、SETOLIA のアンインストールや更新では削除されません。
- 以前のバージョンで同梱テンプレートのフォルダ(`C:\ProgramData\obs-studio\plugins\setolia\data\templates` など)に置いていたカスタムテンプレートは、起動時に自動でユーザーテンプレートフォルダにコピーされます(元のフォルダは残ります)。テンプレートの URL は変わらないため、ブラウザソースを追加し直す必要はありません。
